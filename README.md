# FitPulse Landing Page

Your Personal Fitness Journey Starts Here.

## About

FitPulse is a comprehensive fitness tracking mobile app that helps users track workouts, plan nutrition, and monitor progress. This repository contains the landing page for the FitPulse product.

## Live Demo

**[View Live Demo](https://vahesahakian.github.io/product-landing-devteam/)**

## Features

### v1.0 - Initial Release
- Responsive mobile-first design
- Modern CSS with custom properties
- Semantic HTML5 structure
- Smooth scroll navigation

### v1.0.1 - UX Enhancements (Merged)
- Sticky navbar with shadow effect on scroll
- Intersection Observer for active section highlighting
- CTA modal with signup form (name + email)
- Form validation with required fields and email regex
- Modal close behaviors: X button, backdrop click, Escape key

### Planned for v1.1 (Showcase Interactions)
- Gallery section with 6 images in grid layout
- Filter categories: All / Workouts / Nutrition / Progress
- Lightbox for fullscreen image viewing
- Keyboard navigation in lightbox

## Sections

- **Hero** - Product introduction with app mockup
- **Showcase** - Feature cards highlighting core functionality
- **Benefits** - Key value propositions
- **Testimonials** - User success stories
- **Pricing** - Three-tier pricing structure
- **Footer** - Social links and copyright

## Getting Started

### Prerequisites

- A modern web browser
- No build tools required

### Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/VaheSahakian/product-landing-devteam.git
   ```

2. Open `index.html` in your browser

Or use a local server:
```bash
npx serve .
```
